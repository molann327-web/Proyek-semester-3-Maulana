# Roadmap RAD — Indikatif

Estimasi awal untuk satu tim kecil (1 analis/desainer + 1 front-end developer), belum termasuk backend dan integrasi pihak ketiga. Jadwal aktual perlu disesuaikan setelah workshop kebutuhan.

| Fase RAD | Durasi indikatif | Aktivitas | Output |
|---|---:|---|---|
| 1. Requirement Planning | 2–3 hari | Validasi aktor, scope, alur, status, aturan bisnis | SOT disetujui, daftar asumsi |
| 2. User Design — Shell & Design System | 2–3 hari | Layout, tokens, komponen, dark mode, responsif | UI kit dan shell |
| 3. User Design — Penerimaan | 4–5 hari | Dashboard, formulir, dokumen, verifikasi, seleksi | Prototype penerimaan |
| 4. User Design — Operasional | 3–4 hari | Pembayaran, laporan, master data, tes online | Prototype operasional |
| 5. User Design — Layanan | 2–3 hari | WhatsApp/email queue, asrama, helpdesk, FAQ | Prototype layanan |
| 6. Construction / Iterasi | 4–6 hari | Validasi stakeholder, perbaikan UI, state kosong/error | Kandidat UI |
| 7. Testing & Handover | 2–3 hari | Responsif, aksesibilitas dasar, build, dokumentasi | Paket front-end baseline |

**Total indikatif:** 19–27 hari kerja. Estimasi ini untuk UI/front-end prototype; belum mencakup backend, keamanan produksi, integrasi WhatsApp Gateway, payment provider, atau deployment.

## Checkpoint
- Checkpoint 1: persetujuan SOT dan role
- Checkpoint 2: persetujuan shell + dashboard
- Checkpoint 3: persetujuan formulir dan verifikasi
- Checkpoint 4: persetujuan operasional dan layanan
- Checkpoint 5: uji penerimaan dan serah terima

## Definisi selesai
Build berhasil, 10 modul dapat dibuka, interaksi demo utama berjalan, tema gelap/terang terbaca, layout responsif, batas dummy dinyatakan jelas, serta seluruh dokumen kontrak tersedia.
